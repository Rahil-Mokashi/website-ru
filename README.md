# 10 Months of Us

- Run: `npm install` then `npm run dev`
- Build: `npm run build` (output in `dist/`, deploy that folder to Netlify / Vercel / GitHub Pages)
- Words: `src/data/messages.ts` (her name, letter, secrets, playlist), `memories.ts`, `reasons.ts`, `photos.ts`
- Photos: `public/assets/photos/` (resize new ones with `node scripts/optimize-photos.mjs "<folder>"`)
- Songs: `public/assets/audio/` — file names listed in `playlist` in messages.ts
